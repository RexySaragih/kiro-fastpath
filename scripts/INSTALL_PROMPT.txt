You are installing FastPath (git repo: kiro-fastpath) on this machine for AWS Kiro (IDE/CLI).

GOAL
Portable home at ~/kiro-fastpath (or FASTPATH_HOME), MiniLM + Scout agent, inject hook.
Make Kiro retrieve→act — not walk the repo.

═══════════════════════════════════════════════════════════
REMEMBER (read before installing — first install gotchas)
═══════════════════════════════════════════════════════════

GIT REPO NAME = kiro-fastpath
- Clone/pull the product repo as kiro-fastpath (not your app repo).
- Preferred path: ~/kiro-fastpath (or Documents/kiro-fastpath as the clone, then install-home).
- Zip is OPTIONAL (USB/airgap only).
- After git pull of kiro-fastpath: `fastpath upgrade` then `fastpath rewire --all`
  (or: npm ci && npm run build, then use/rewire each app).
- npm package.json name stays "fastpath"; folder/git name is kiro-fastpath.

TWO PATHS — DO NOT MIX THEM UP
1) install-home.sh ARG = kiro-fastpath checkout (the product)
2) install-target.sh ARG = your application repo
- Never pass your app repo (or a README.md file) to install-home.sh.

ONE HOME, MANY REPOS
- FASTPATH_HOME (default ~/kiro-fastpath) = the product install.
- Each project keeps its own .fastpath/index.db and .kiro/ wiring.

AGENTS
- Scout = context-gatherer sub-agent — model claude-haiku-4.5, session /effort low. Read-only.
- Architect = bigger work — model claude-sonnet-4.5, session /effort medium. Can spawn Scout.
- Effort is NOT per-agent in Kiro; run /effort when switching agents.
- NEVER put allowedTools / includeMcpJson in agent files —
  Kiro IDE silently drops the agent. doctor must say "Agent pack IDE-compatible".
  toolsSettings.subagent is allowed (Architect trusts Scout).

KIRO ONLY USES FASTPATH WHEN ALL THREE EXIST
1) UserPromptSubmit hook fastpath-auto-context (auto-inject STDOUT)
2) Scout agent with inline mcpServers + @fastpath tools
3) Index built (MiniLM for SCOUT READY)

FRESHNESS
- Every prompt: delta reindex ≤20 dirty files (2s budget) then retrieve.
- Long sessions: fastpath watch
- After big git pull of the *project*: fastpath index --git
- After kiro-fastpath upgrade: full fastpath index once

MOVED OR NEW MACHINE
- Hooks/MCP embed absolute paths + FASTPATH_HOME env.
- Relocate home → re-run: fastpath rewire --all  (or use "$WORKSPACE")

VERIFY (do not say "use FastPath")
  "Where is RunEngine defined, and who calls performVaultLogin?
   Open at most 3 files, then stop. Don't edit yet."

DEBUG
- fastpath doctor / doctor --json / home / metrics --summary / repair-native
- scripts/OFFICE_RUNBOOK.txt · SECURITY_NOTES.txt · SUPPORT_MATRIX.txt

DO NOT
- Pass app repos to install-home
- Install @xenova/transformers or native tree-sitter grammar packages
- Commit node_modules or .fastpath index DBs

INSTALL STEPS
═══════════════════════════════════════════════════════════

A) Home (once) — product repo kiro-fastpath
   git clone <kiro-fastpath-url> ~/kiro-fastpath
   # or already cloned e.g. ~/Documents/kiro-fastpath:
   bash /path/to/kiro-fastpath/scripts/install-home.sh /path/to/kiro-fastpath

B) Wire APP repo
   export FASTPATH_HOME=~/kiro-fastpath
   bash "$FASTPATH_HOME/scripts/install-target.sh" /path/to/your-repo

C) Verify
   node "$FASTPATH_HOME/packages/cli/dist/index.js" doctor /path/to/your-repo
   Expect: SCOUT READY

HUMAN: Reload Kiro → trust workspace → Default (spawn Scout to gather) → enable fastpath-auto-context
       Scout: /effort low · Architect: /effort medium
